# VaultBranch

[English](README.md) | [简体中文](README_zh.md)

为 Obsidian 提供 Git 侧栏和提交历史图。

- 查看文件改动、差异和提交历史。
- 在差异页编辑工作区文本，按 Ctrl/Cmd+S 保存，不自动暂存。
- 在设置中切换中文 / English。
- 点击撤销箭头丢弃未暂存改动；未跟踪文件移入回收站。
- **Pull**：拉取远程改动。
- **Push**：推送本地提交。
- **Commit staged**：只提交暂存区的改动。
- **Stash push**：收起尚未提交的改动，留待之后恢复。
- **Stash pop**：恢复选中的 Stash，成功后删除该记录；发生冲突时保留记录。

仅支持桌面端，需要本机安装 Git。
