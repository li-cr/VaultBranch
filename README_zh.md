# VaultBranch

[English](README.md) | [简体中文](README_zh.md)

为 Obsidian 提供 Git 侧栏和提交历史图。

- 查看文件改动、差异和提交历史。
- 右键查看文件历史，跟随 Git 识别的重命名，对比每次提交的修改。
- 创建、切换本地分支，也可从图中选中的提交创建分支。
- 直接在差异页右侧编辑并实时高亮，按 Ctrl/Cmd+S 保存，也可开启自动保存。
- 未修改内容默认折叠，可在其他设置中开关 CodeMirror 原生折叠。
- 使用 ↑ / ↓ 跳转差异，可在其他设置中控制按钮显示。
- 输入 `@date` 或用快捷键插入时间，在其他设置中配置格式。
- 在设置中切换中文 / English。
- 点击撤销箭头丢弃未暂存改动；未跟踪文件移入回收站。
- **Pull**：拉取远程改动。
- **Push**：推送本地提交。
- **Commit staged**：只提交暂存区的改动。
- **Stash push**：收起尚未提交的改动，留待之后恢复。
- **Stash pop**：恢复选中的 Stash，成功后删除该记录；发生冲突时保留记录。

仅支持桌面端，需要本机安装 Git。
