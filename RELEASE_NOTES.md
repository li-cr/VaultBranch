VaultBranch 1.0.0 is the 1.0 milestone release.

- Git sidebar with staging, commits, pull and push.
- Editable text diffs, commit graph, file history, branches, Stash and conflict resolution.
- Image comparisons with wheel zoom, drag to pan and double-click reset; the minimum zoom is the initial fit.

This release updates version metadata from 0.2.38 to 1.0.0. Plugin behavior is unchanged. Version consistency and the build were checked locally; the release workflow runs the automated suite.

Release assets retain GitHub provenance attestations. Desktop only; requires Git installed separately.
