# Optional JSON and Markdown syntax highlighting

Baseline: 0.2.23, commit `1782234`. Candidate: 0.2.24 (the commit containing this document). This is an optional feature with measured overhead, not a performance improvement claim.

## Implementation

The default-off setting supports `.json`, `.md` and `.markdown`, case insensitive. Editable, staged and history MergeViews use compartments without replacing editors. Historical entries use their historical extensions. The host provides CodeMirror language/state/view and Lezer runtimes; the bundle contains JSON and official Lezer GFM Markdown grammars. Markdown stays source text with one fenced-code style, without nested grammars, preview, completion or extra editing keymaps.

Parsers initialize only for enabled supported comparisons. Startup defers editors even with the preference on. With the default off, no highlighting compartments or parser initialization are needed. Immutable document limit checks are weakly cached. Both panes use plain text if either exceeds 200,000 UTF-16 characters or a line exceeds 10,000. Limit transitions apply after the active editor transaction; undo restores highlighting. Stale work is ignored after toggling, switching or closing. Scoped theme colors retain diff backgrounds; toggles preserve drafts, selection and undo without saving or staging.

Host modules were checked in the local version below. Older supported Obsidian versions and Linux/macOS UI were not tested locally.

## Environment and method

Windows 10 build 19045, Obsidian/installer 1.15.0, Electron 43.8.4, embedded Node 24.22.1, Git 2.50.0.windows.1. Independent `note_test`: 7 indexed files including the startup fixture, 8 tracked files, 6 commits, 4 stashes. Legacy `my-git` disabled. Warm OS/V8 caches. Run scripts serially with no dirty diff sessions, builds or other tests running. Scripts restore preferences and trash synthetic files.

Install the three 0.2.23 release assets preserving data.json, run `scripts/benchmark-startup.js`, install the candidate and repeat with syntaxHighlighting=false. Each collection discards one warm-up and retains five samples. Reload includes script evaluation, onload and CSS, with sidebar closed and openOnStartup=false. Sidebar includes Git/status/layout; the first diff is an 80-line untracked Markdown file including Git/file reads, editor creation and synchronous layout. These are plugin reload/first-use timings, not application cold start or completed paint.

The initial first-diff result worsened, so both builds were reinstalled and rechecked. Both collections are retained: the reversal does not establish a repeatable regression or improvement. An earlier candidate collection run alongside the full test suite was discarded for load interference before these final collections.

## On versus off

Run `scripts/benchmark-highlighting.js` on the candidate. It alternates modes, discards one warm-up per mode/language and records five samples each. JSON: 71,783 characters, 2,003 lines. Markdown: 146,090 characters, 2,001 lines. Both are synthetic untracked files; autosave/folding off. Opening includes Git/file reads, configuration and synchronous layout. Thirty visible-line insert transactions each force layout; batch timing excludes disk/Git and final paint. Raw results also include two animation frames, which do not guarantee all background parsing has completed. First parser initialization is outside retained samples.

| Scenario and scale | Metric and unit | Off | On | Samples and method |
| --- | --- | --- | --- | --- |
| JSON, 2,003 lines | Open/layout ms | 242.0 (237.2–289.8) | 252.9 (243.8–295.7) | 5/mode; openDiff/configuration/layout |
| Same JSON | 30-insert batch ms | 60.7 (47.6–71.4) | 75.2 (73.6–107.6) | 5/mode; dispatch/layout |
| Markdown, 2,001 lines | Open/layout ms | 245.8 (236.6–261.6) | 262.0 (242.7–279.6) | 5/mode; same method |
| Same Markdown | 30-insert batch ms | 58.0 (49.9–75.5) | 99.1 (94.6–131.9) | 5/mode; same method |

Highlighting adds work, especially Markdown editing. These are local warm synthetic operations, not typing-to-paint latency, cold parser timing, P95 or overall application performance. Keep the setting off for lowest editing overhead. Raw samples and all four startup collections: [0.2.24-highlighting.json](0.2.24-highlighting.json).

## Correctness

80 local automated tests pass, including nine highlighting regressions and an opt-in startup deferral check. 81 local Obsidian UI assertions pass: 25 syntax UI, 8 syntax/history, 24 chunk-revert and 24 navigation checks. They cover native toggle persistence, both-pane JSON tokens, Markdown source colors, live toggles, drafts/selection/undo, staged/history readonly modes, historical rename paths, unchanged index, hidden JSON autosave, unsupported files, size limits and edit/undo transitions, cleanup, native reverts and navigation. No runtime errors were captured. Reproducible UI scripts are documented in `tests/manual/README.md`.
