# VaultBranch 0.2.21 startup measurements

Baseline: `7a93808` / release `0.2.20`. Candidate: the startup implementation released as tag `0.2.21`. Only main.js was swapped for the final baseline runs; both variants used the same 0.2.21 manifest/CSS, so the raw plugin metadata says 0.2.21 for both.

## Changes

- Use Obsidian's host-provided `@codemirror/state`, `view`, `commands` and `language` instead of bundling duplicate core modules. `@codemirror/merge` remains bundled because the host does not provide it.
- Register synchronous view factories; evaluate each view implementation on first creation, including restored workspace leaves. A closed sidebar does not initialize any view or CodeMirror. No timer delays registration or moves a restored editor to an artificial later phase.
- Merge missing preference defaults in memory. Save them on a real preference change, avoiding an upgrade/first-install settings write during startup. Existing saved and unknown preferences survive.

## Environment and method

Local Windows 10 build 19045, Obsidian **1.15.0** (installer 1.12.7), Electron 39.8.3, embedded Node 22.22.1, Git 2.50.0.windows.1. Same live `note_test` vault: 7 indexed files including one disposable 80-line untracked fixture, 8 tracked Git files, 6 commits, 4 stashes. No Git writes in the benchmark. The sidebar is closed and `openOnStartup=false` during each timed load; existing preferences and startup behavior are restored afterward.

One warm-up and five measured iterations per variant. OS/V8 caches are warm. `app.plugins.loadPlugin` includes host script loading/evaluation, constructor, awaited onload and CSS; it does not include first sidebar/diff creation. `beforeOnloadMs` ends at entry to the host component load method. Sidebar timing includes initialization, Git status and synchronous layout. Diff timing includes Git/file reads, MergeView construction and synchronous layout. These timings do **not** measure completed pixel paint, application cold start, all plugins together or a large real vault. The reported 800 ms was not reproduced; these results cannot establish an 800 ms to 12 ms improvement.

Saved-preferences variants include every default key. Legacy variants remove `collapseUnchanged` and `showDiffNavigation` before every measured load, outside the timer. Background application/disk work can produce queue spikes; all measured samples, including outliers, are retained. Combined hot-swapping attempts lost the isolated test renderer and yielded no results; the test app was restarted before the final four runs. The old prototype plugin was disabled, and no other community plugins were running during these recorded measurements.

Saved-preference reload median fell from 26.4 to 11.7 ms (about 56%). The direct loader/evaluation/construction segment fell from 22.2 to 10.0 ms. The bundle is about 68% smaller. The legacy variant also avoids one settings write; its total timing difference includes read-queue variation, so it does not isolate the write's duration.

First-use timings did not improve: the saved-preference first-sidebar median rose from 239.5 to 255.1 ms; first diff rose from 214.6 to 224.2 ms. Legacy medians rose from 241.8 to 255.9 ms for sidebar and 217.1 to 239.0 ms for diff. Deferred initialization and ordinary host/Git variability both affect those operations; this experiment does not isolate them. No overall application or first-view speedup is claimed. Keep this modest first-use tradeoff visible when assessing the startup reduction.

Raw samples and environment: [0.2.21-startup.json](0.2.21-startup.json).

## Reproduce

Use only an isolated vault named `note_test`, with Git installed, clean/saved diff sessions and VaultBranch enabled. Build and install the baseline's three assets in that test vault, preserving data.json. Execute the contents of `scripts/benchmark-startup.js` using Obsidian eval or its developer console and save the returned object. It closes plugin views, creates and trashes its fixture and restores preferences; do not run in a working vault.

Run once with `window.__vaultbranchBenchmarkLegacy=false` and once with it `true`; remove that flag afterward. Install the candidate's three assets, preserving data.json, and repeat with the same repository and host. The script refuses other vault names and unsaved/saving sessions. Compare all returned samples, not just the fastest one. For full cold-start or a reported 800 ms delay, separately instrument application startup on that environment; those scenarios remain unmeasured here.

## Correctness

All 66 local automated tests passed. Startup regressions cover deferred view/editor loading, synchronous restored-sidebar factories, class reuse, startup sidebar preference, defaults without writes, preference persistence and invalid-language fallback. The 101 real Obsidian checks cover all five restored view types, serialized manual drafts, editable/index access, diff navigation, folding, undo/drafts, file history, autosave, hidden JSON, external-change protection and session cleanup. Shared host CodeMirror packages are verified in this Obsidian version; other Obsidian versions and Linux/macOS UI were not measured.
